# European Auto Center — Diagnostics Website (sample)

Single-page site for in-shop ($160) and mobile ($300) vehicle diagnostics.
Hosted with GitHub Pages: Settings → Pages → Branch `main`, folder `/ (root)`.

- Booking requests are emailed via FormSubmit to the address in `SHOP_EMAIL` (index.html); first submission sends an activation email that must be confirmed once. If sending fails, customers are offered a prefilled text to 682-553-6089.
- Logo (`images/logo.svg`) is traced from the shop's printed work order.
- To confirm with the owner: Saturday hours, Google rating (currently 4.5 from public listings), real Google review quotes.
