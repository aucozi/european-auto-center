# European Auto Center — Diagnostics Website (sample)

Single-page site offering in-shop ($160) and mobile ($300) vehicle diagnostics.

Hosted with GitHub Pages: Settings → Pages → Branch `main`, folder `/ (root)`.

Remaining placeholders (highlighted yellow): three Google review quotes, and whether the diagnostic fee is credited toward repairs. Logo is a wordmark recreated from the shop sign. Hours and rating come from public listings (Birdeye, Yelp); confirm with the owner.
