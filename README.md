# European Auto Center — Diagnostics Website (sample)

Single-page site offering in-shop ($160) and mobile ($300) vehicle diagnostics.

Hosted with GitHub Pages: Settings → Pages → Branch `main`, folder `/ (root)`.

Remaining placeholders (highlighted yellow): three Google review quotes, and whether the diagnostic fee is credited toward repairs. Logo (images/logo.svg, images/logo-white.svg) is traced directly from the logo printed on the shop's work order. Hours and rating come from public listings (Birdeye, Yelp); confirm with the owner.
